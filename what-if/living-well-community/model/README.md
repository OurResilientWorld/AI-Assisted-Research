# Living Well calculation notes

These are planning assumptions, not measured programme results. Amounts are 2026 Australian dollars unless marked nominal. No funds, supplier prices, university contract or commercialisation income is committed.

Run `python3 model.py` in this directory to reproduce inputs.json and the eight CSV tables. Python 3 standard library is sufficient. service-cost-assumptions.json defines direct participant costs; model.py defines the overhead, funding, cohort and scenario assumptions. D1 is the association base overhead; D2 is a lower-overhead sensitivity for the same association, not a different legal structure.

The $120,000 initial/pilot research allowance is unquoted. Comparative and long-term research need separate secured funding and are excluded from the service-operating cashflow. No grant or royalty revenue is assumed. See the supporting analysis for all four value accounts and viability limits.
