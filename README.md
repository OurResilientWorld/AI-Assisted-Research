## Resilience Simulations

Interactive examples for exploring priorities, trade-offs and declared assumptions. These simulations support discussion; they are not surveys, forecasts or predictions.

- [Bega Valley community resilience trade-off simulation][bega-valley-simulation] — Distribute 100 effort points across six connected action areas and inspect an explicitly synthetic citizens' response summary.
- [Australia bushfire resilience cost and timing simulation][australia-bushfire-simulation] — Test four resilience actions and compare remaining losses, intervention spending and total scenario costs to 2035 or 2050.
- [Demo Bushfire Readiness Simulator][demo-bushfire-readiness-simulation] — Compare business-as-usual risk with the risk remaining after four selected actions and test how an Extreme El Niño assumption changes their relative effect.

## Contribute

Use the repository issue forms to propose a correction, submit new evidence, outline a research
proposal or report an accessibility barrier. Issues are public: do not submit confidential,
sensitive or personal information. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Governance

A contribution does not automatically change a finding. Material changes return to evidence review
and Product Owner acceptance. Published changes are versioned and visible in Git history.

This collection continues the published material from [AI-Policy](https://github.com/OurResilientWorld/AI-Policy). Existing paths, report wording, original citations and licences are retained. New feedback belongs in this repository's issue forms.

## What If Research

[Browse What If Research](https://research.ourresilient.world/what-if/index.html). The first programme, [Time and Personal AI to 2035](https://research.ourresilient.world/what-if/time-and-personal-ai-to-2035/index.html), contains six full reports, a [reusable method](https://research.ourresilient.world/what-if/method/index.html) and inspectable evidence/calculation downloads. What If begins from labelled design premises and investigates responsible implementation; designed success is not observed proof or a forecast.
